Self-host Bitwarden miễn phí với Cloudflare Workers

Hướng dẫn triển khai NodeWarden, server bên thứ ba tương thích với ứng dụng Bitwarden, sử dụng Cloudflare Workers, D1, Durable Objects và R2.

HTML đơn fileKhông cần VPSChecklist lưu cục bộCập nhật 06/08/2026
Quan trọng: NodeWarden không phải Bitwarden Server chính thức và cũng không phải Vaultwarden. Không dùng đây làm bản sao duy nhất của dữ liệu; luôn có backup độc lập.

1. Kiến trúc

Cloudflare Worker

Phục vụ API tương thích Bitwarden và Web Vault.

D1 Database

Lưu tài khoản, cipher, metadata và cấu hình.

R2 Object Storage

Lưu attachment, Send và bản backup S3.

Durable Objects

Thông báo đồng bộ và tiến trình liên quan đến backup.

Chuẩn bị

2. Triển khai NodeWarden

Fork repository

Fork repository NodeWarden vào tài khoản GitHub và giữ branch mặc định là main.

Mở repository NodeWarden

Kết nối GitHub với Cloudflare

Vào Workers & Pages → Create application → Import a repository, rồi chọn fork của bạn.

3. Thiết lập JWT_SECRET

Tạo secret ngẫu nhiên dài ít nhất 32 ký tự. Không dùng chuỗi mẫu và không commit lên GitHub.

Linux hoặc macOS

openssl rand -base64 48

Windows PowerShell

$bytes = New-Object byte[] 48
[Security.Cryptography.RandomNumberGenerator]::Fill($bytes)
[Convert]::ToBase64String($bytes)

Thêm secret tại:

Workers & Pages
→ nodewarden
→ Settings
→ Variables and Secrets
→ Add Secret
TrườngGiá trị
NameJWT_SECRET
ValueChuỗi vừa tạo
Không tự ý thay JWT_SECRET sau khi đã vận hành. Việc đổi secret có thể làm mất hiệu lực token và gây lỗi cấu hình backup.

4. Gắn custom domain

Vào Worker → Settings → Domains & Routes → Add → Custom Domain.

vault.example.com

Server URL trong ứng dụng Bitwarden:

https://vault.example.com
Không thêm /api, /identity hoặc /web.

5. Backup lên Cloudflare R2

Tạo bucket riêng

nodewarden-backup

Không dùng chung bucket attachment làm nơi backup.

Tạo R2 S3 credentials

Tạo User API Token có quyền Object Read & Write, chỉ áp dụng cho bucket backup. Lưu Access Key ID và Secret Access Key.

Lấy Account ID

Vào R2 Overview → Account details hoặc Account Home → Copy account ID.

https://ACCOUNT_ID.r2.cloudflarestorage.com

Remote pathnodewarden
Storage classSTANDARD hoặc để trống

6. Cài trên Windows 11

Bitwarden Desktop

Cài bản Windows installer chính thức để quản lý vault, dùng Windows Hello và browser integration.

Trang tải Bitwarden

Browser extension

Cài extension Bitwarden chính thức cho Edge, Chrome hoặc Firefox để autofill.

Kết nối NodeWarden

  1. Tại màn hình đăng nhập, chọn Logging in on → Self-hosted.
  2. Nhập https://vault.example.com.
  3. Đăng nhập bằng email, master password và 2FA.

Cấu hình khuyến nghị

Phím tắt autofill: Ctrl + Shift + L.

7. Chuyển dữ liệu từ 1Password

Xuất 1PUX

Trong 1Password, dùng Export và chọn định dạng 1PUX nếu có.

File 1PUX không được mã hóa. Không gửi qua email hoặc tải lên cloud.

Import vào NodeWarden

Tools → Import data
Format: 1Password (1pux)
Vault: My vault

Kiểm tra dữ liệu

  • Login và URI
  • Secure Notes
  • Custom fields và TOTP
  • Cards, identities, recovery codes
  • Attachment và passkey cần xử lý thủ công

8. Sửa lỗi “S3 listing failed: HTTP 400”

Endpoint

Dùng:

https://ACCOUNT_ID.r2.cloudflarestorage.com

Không thêm bucket vào endpoint và nên bỏ dấu / cuối.

Region và addressing

Region = auto; Addressing style = Path-style.

Credentials

Dùng R2 Access Key ID và Secret Access Key, không dùng Cloudflare API Token thường.

Tên bucket

Tên phải khớp tuyệt đối, ví dụ nodewarden-backup, không có slash.

EU jurisdiction
https://ACCOUNT_ID.eu.r2.cloudflarestorage.com

9. Downtime và dùng offline

Trạng tháiKhi server down
Đã đăng nhập, vault bị LockCó thể mở khóa bản cache offline.
Đã Log outKhông đăng nhập lại được đến khi server hoạt động.
Thêm hoặc sửa mật khẩuKhông đồng bộ; nên coi vault offline là chỉ đọc.
Thiết bị mớiKhông thể đăng nhập hoặc tải vault.
Attachment và SendCó thể không truy cập được.
Trên mọi thiết bị, đặt Vault timeout action = Lock, không đặt Log out.
  • Giữ ít nhất hai thiết bị đã đăng nhập.
  • Backup hằng ngày sang nơi ngoài tài khoản Cloudflare.
  • Lưu JWT_SECRET và recovery code ngoại tuyến.
  • Backup trước khi Sync fork hoặc cập nhật.
  • Không bật auto-deploy hoàn toàn cho password manager.
